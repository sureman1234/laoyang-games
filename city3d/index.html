玩法说明 （点此收起 / 展开）

目标：把空地养成有钱、有人、满意度高的城市。

操作

左键建造（拖动可连铺道路）
右键拖旋转视角
滚轮缩放远近
中键拖平移画面
WASD平移 · QE 旋转
1~6选建筑 · X 拆除
Esc取消选择
空格暂停 / 继续

6 种建筑

1 道路骨架，建筑须挨着路才有效
2 住宅住人，产生人口与容量
3 商业提供岗位、收税
4 工业大量岗位，略带污染
5 公园提升满意度
6 电厂每座供 400 电

发育顺序

修路 → 路边划住宅 → 建电厂通电 → 建商业/工业招人 → 点缀公园提满意度。建筑满足条件会自动长高升级。

看板

左上：资金 / 人口 / 电力 / 满意度 / 时间；左下：容量 / 岗位 / 净收益 / 税率；右上：速度 · 存档 · 读档 · 清屏。

常见卡点

· 电不够 → 建筑长不动，多盖电厂
· 满意度<35% → 人口流失（缺电 / 没公园 / 税太高 / 污染重）
· 不赚钱 → 补商业工业让人交税

滚轮 缩放 · 中键拖动 平移
WASD 平移 · QE 旋转
1-6 选建筑 · X 拆除
Esc 取消 · 空格 暂停
